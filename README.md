# Password-Manager
Python script to manage your account logins because every now and then we tend to forget our passwords

Created the visual application using Tkinter and is now in english with the functions to create a new password, delete an existing one and editing aswell and the option to decrypt them so you can actually see your credentials.

Also has a search bar for the user to be able to look for a more specific account or a combination of letters.

Added a more complex method to encrypt the password aswell as to decrypt it.
